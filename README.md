# 缠论股票分析 Agent

[![CI](https://github.com/lzh1229862/chanlun-stock-agent/actions/workflows/ci.yml/badge.svg)](https://github.com/lzh1229862/chanlun-stock-agent/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

本地运行的 A 股缠论分析工具：拉日线 → 算分型/笔/中枢 → 识别三类买卖点 → 过滤 → 回测 → 出中文报告（LLM 可选）→ 归档 Markdown / CSV / SQLite。另有 Streamlit 界面与定时任务。

> **技术验证与学习用工具**：按缠论规则机械地生成结构化描述，不预测涨跌、不承诺收益、不含下单。
> **不构成任何投资建议。**

# 第一层：结论速览（30 秒）

## ✅ 已验证 —— 通过了时间样本外（训练 2015-2020 / 检验 2021-2026）

| 结论 | 检验期实测 | 出处 |
| --- | --- | --- |
| **六类信号都有超额** | 5 日 +0.90% ~ +1.96%，CI 全不跨 0，分半全一致 | ADR-029 |
| **买点在三种市场状态下都有真 alpha** | 上行 +1.67% / 震荡 +1.73% / 下行 +1.47%（vs 沪深300） | ADR-029 |
| **规则不只对知名股有效** | 随机 35 只 vs 知名 10 只，差值 CI 跨 0 | ADR-020 |
| **排序打分** | 检验期 score2 − score0 = +1.67% / +2.28% / +3.48% | ADR-024 |
| **组合优于单因子** | 增量价值 3 假设 x 3 窗口 = 9/9 通过 | ADR-026 |
| **幸存者偏差没让数字虚高** | 退市股超额反而**更高**（+0.42% / +0.34% / +0.50%，252 只全量） | ADR-035 |
| **成本上很稳健** | 打分能扛到 3% 往返成本（现行假设的 15 倍） | ADR-032 |
| **发现远超运气** | 119 次有区间估计的检验里 78 个发现，运气只期望 6.0 个（全项目记账 180 次） | ADR-033 |

## ⚠️ 已推翻 / 已修正（这些是本项目最有价值的部分）

| 曾经以为 | 实际是 | 出处 |
| --- | --- | --- |
| 规则只对知名股有效（幸存者偏差） | 随机股一样有效，退市股甚至更好 | ADR-020 / 035 |
| 第三类卖点接近随机，建议砍掉 | 超额 +1.15% 且 CI 不跨 0 | ADR-019 |
| 周线级别共振有帮助 | **显著为负**（二三买 −1.8%） | ADR-019 |
| 买点在任何状态下都没有 alpha | 三种状态**全部**显著为正 | ADR-019 |
| 卖点只在上涨状态有效 | 三种状态**全部**显著 | ADR-029 |
| 样本内的数字可以照用 | 要**打五到六折**（固定股票池后衰减 41~49%） | ADR-024 / 031 |
| H3「距中枢」是独立结论 | **不过 FDR**，只是打分里的组合因子 | ADR-033 |
| 全市场扫描扫的是全市场 | 当时只扫了 3%（156/5020） | — |
| 「背驰强度」（MACD 面积比）能给信号加分 | **5 条检验 0 条显著、4 条方向相反**（一类点本来就带背驰硬过滤，信息已被消耗） | ADR-037 |

# 第二层：怎么用（2 分钟）

## 环境

Windows + Python 3.12（其他平台未验证，依赖含 Rust 编译轮子 `czsc`）。

```bash
pip install -r requirements.txt
```

## 三条主力命令

```bash
python main.py                     # 每日批处理：出报告 + 归档
python -m streamlit run app.py     # 网页界面（或双击 run_ui.bat）
python run_queue.py                # 长任务队列（见下）
```

## 网页界面（Streamlit，三个模式）

| 模式 | 用途 |
| --- | --- |
| **单股分析** | 搜索 → K 线缠论标注 → 信号明细（带打分/距中枢）→ 回测参考 → 本股打分历史 → AI 总结按需生成 |
| **自选股与日报** | 编辑股票池（可命名、显示公司名）、查看历史日报、**信号失效自检** |
| **全市场买点** | 扫全市场的买点，三个筛选控件，**点一行跳单股分析** |

默认**白天皮肤**，左下角开关切夜晚。

## 长任务队列（一次跑完，可中断可续跑）

有几件事跑一次要几十分钟到几小时，**在 agent 里跑不了**（单次调用有 10 分钟上限）。用这个：

```bash
python run_queue.py --status     # 看进度
python run_queue.py              # 依次跑完所有未完成的
python run_queue.py --only scan  # 只跑一个
```

| 任务 | 首次耗时 | 续跑机制 |
| --- | --- | --- |
| `delist_fetch` 退市股取数 252 只 | ~50 分钟 | `data/delisted/*.parquet` 存在性 |
| `delist_compute` 退市股信号重算 | ~35 分钟 | `data/survivorship_cache.json` |
| `survivorship` 幸存者偏差对比 | 几秒 | 只读缓存 |
| `scan` 全市场买点扫描 5020 只 | 首次 ~4.5 小时 | `scan_state` 表 |
| `daily` 每日批处理 | ~12 分钟 | `reports/{date}/report.md` |

> Ctrl+C 随时可中断，重跑自动跳过已完成的。
> **别和 Windows 计划任务（工作日 18:05）同时跑** —— SQLite 写会互相锁。

## 常用命令行

```bash
python main.py --date 2026-09-18 --no-llm     # 指定日期、不调 LLM
python main.py --stocks 600519,000858         # 临时换一批股票
python backtest.py --scope both               # 只重跑回测
python market_scan.py --limit 50              # 全市场扫描先试跑 50 只
python market_scan.py --report                # 只看已扫结果
```

# 第三层：设计要点（按需）

## 数据源

| 用途 | 来源 |
| --- | --- |
| 日线行情 | 腾讯 `qt.gtimg.cn`（**东财在本机被整机封禁**，见 ADR-001） |
| 前复权因子 | 新浪 `stock_zh_a_daily` |
| 指数 | 新浪 `stock_zh_index_daily` |
| 60 分钟 | 新浪 `stock_zh_a_minute`（**固定只给 1970 根 ≈ 2 年**） |
| 基本面 | 巨潮（概况/行业）+ 同花顺（财务）+ 腾讯（估值） |
| 批量当日行情 | 腾讯行情一次查 50 只，**只在收盘后用** |

## 存储（都已被 gitignore）

```
data/raw/{code}.parquet        日线：不复权价 + qfq_factor（ADR-002）
data/index/{code}.parquet      指数（与股票分开，代码会撞车）
data/minute/{code}.parquet     60 分钟
data/delisted/{code}.parquet   退市股（与统计样本分开，避免污染）
data/factor/{code}.parquet     复权因子缓存（TTL 7 天）
data/chan_agent.db             SQLite：signals / backtest / reports / profiles / fundamentals
                               + scan_results / scan_state
```

## 几个关键机制

- **三日期**（ADR-012）：`signal_date`（笔结束日）/ `confirm_date`（实测延迟）/ `entry_ref_price`
- **回测入场**（ADR-011）：确认日**次一交易日开盘**。不能按信号日收盘成交 —— 那本身是未来函数
- **涨跌停顺延**（ADR-030）：入场日开盘封在涨停（买点）/ 跌停（卖点）时顺延到能成交的交易日
- **结构距离**（ADR-021/033）：距最近中枢结束 ≥10 日的历史超额偏低。**注意：H3 单独不过 FDR，只是打分里的组合因子**
- **排序打分**（ADR-023/024）：`score = [中枢宽度>=0.12] + [距中枢结束<10日]`，已过时间样本外
- **数据兜底**（ADR-015）：`ensure_kline` 本地缺失/过期自动拉，失败返回结构化错误而不抛异常

# 已知限制

- **数据深度不一致**：`data/raw` 里 45 只是 11 年、约 170 只（扫描来的）只有 2 年。**误纳入会污染统计**
- **退市股只重算了 95/252**（其余排队中，跑 `run_queue.py` 补）
- **60 分钟数据只有 2 年**，数据源限制，无法延长
- **没有容量约束分析**：假设每笔下单量相对日成交额很小
- **没有实盘验证**：全部是回测
- **交易成本是假设值**：滑点分层表（5 档）没经过实盘校准
- **数据源单点**：腾讯 + 新浪，无备用源；批处理失败无告警
- **周线/60 分钟共振均未获支持**：多级别这条路在日线信号上目前没有正面证据
