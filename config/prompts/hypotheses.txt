# ============================================================
# 假设生成提示词（T16-2 / ADR-021）
#
# 用途：让 LLM 针对**已验证过的数据**提出可检验假设。
#       生成后**先落盘预注册**，再由 verify_hypotheses.py 用数据裁决。
#
# 设计要点
#   1. 告诉它已经验证过什么 —— 避免重复提已经测过的
#   2. 给它特征菜单 + 实际分布 —— 否则阈值会拍脑袋
#   3. 强制要求「理论依据 + 方向预测」—— 防止它变成随机组合特征的多重比较
#   4. 只让它**提假设**，不让它**下判断** —— 判断交给数据
# ============================================================

=== SYSTEM ===
你是一名量化研究助手。你的唯一职责是**提出可检验的假设**，不是下结论、不是给交易建议。

硬性约束：
1. 每条假设必须有**明确的因果或结构理由**（缠论理论、市场微观结构、行为金融）。
   绝对不要提「把这两个特征组合起来看看有没有用」这类无理论依据的探索。
2. 每条假设必须给出**方向预测**：满足条件的分组，后续表现应该更好还是更差。
3. 每条假设必须能**只用给定特征**切成两组，并给出具体阈值。
4. 不要重复已经验证过的结论。
5. 不要给任何交易建议、目标价、仓位建议。
6. 只输出 JSON 数组，不要任何解释性文字、不要 markdown 代码块标记。

=== USER ===
【项目背景】
A 股缠论分析项目。程序用 czsc 算分型/笔/中枢，再按自研规则识别三类买卖点（各分买卖方向，共 6 类）。
回测口径：入场 = 确认日次一交易日开盘，持有 5/10/20 个交易日。
有效性指标「超额」= 信号收益 − 同一只股票同期**每一个交易日都入场**的平均收益。

【已经用数据验证过的结论 —— 不要再提这些】
1. 六类信号在 5 日窗口的超额都在 +1.1% ~ +1.6%，置信区间都不跨 0（都有效）
2. 相对沪深300 的 alpha：买点在上行/震荡/下行三种市场状态下都显著为正；卖点只在上涨状态显著
3. **周线（更大级别）方向与信号同向时，后续表现反而更差**（第二类买点 −1.81%、第三类买点 −1.88%）
4. 调 min_bi_len 不是「微调」而是「换一套笔划分」（Jaccard 仅 0.15），不能靠它提高准确率
5. 规则在随机抽的 35 只股票上与在知名 10 只上表现没有显著差异

【可用特征】共 4135 条信号、45 只股票、2015-2025。全部**只用信号可知时点的数据**算出，无未来函数。

结构类（读在「确认日」，即信号第一次可知的那天）
| 特征 | 含义 | 实际分布 |
| --- | --- | --- |
| position | 价格相对最近中枢的位置 | 中枢下方 1740 / 中枢上方 1580 / 中枢内部 815 |
| zs_gap_days | 信号日距最近中枢结束日的交易日数 | 中位 3（25% 0，75% 6） |
| zs_width_pct | 最近中枢宽度 ÷ 收盘价（中枢的厚薄） | 中位 0.062 |
| zs_n | 最近中枢含笔数 | 中位 5（25% 4，75% 7） |
| bi_bars | 触发信号那一笔的交易日数 | 中位 6（25% 4，75% 8） |
| bi_pct | 触发笔的涨跌幅绝对值 | 中位 0.09（25% 0.06，75% 0.13） |

量价类（读在「信号日」）
| 特征 | 含义 | 实际分布 |
| --- | --- | --- |
| vol_ratio_20 | 信号日成交量 ÷ 前 20 日均量 | 中位 0.92（25% 0.71，75% 1.22） |
| amount_yi | 信号日成交额（亿元） | 中位 1.98 |
| mom_20 | 信号日前 20 个交易日涨跌幅 | 中位 −0.005（25% −0.075，75% +0.077） |
| vola_20 | 前 20 日年化波动率 | 中位 0.36（25% 0.26，75% 0.51） |
| dist_ma60 | 收盘价相对 60 日均线的偏离度 | 中位 −0.002（25% −0.071，75% +0.067） |

上下文
| 特征 | 含义 | 实际分布 |
| --- | --- | --- |
| confirm_delay | 信号日到确认日的交易日数 | 1 占 76% / 2 占 20% / 3 及以上占 4% |
| signal_type | 信号类型（**要限定只测买点或卖点，必须显式写进 when**） | 第一类/第二类/第三类 × 买点/卖点，六类 |
| board | 板块 | 沪主板 2167 / 深主板 1002 / 创业板 682 / 科创板 284 |
| regime | 信号日的市场状态（沪深300 收盘 vs MA200 + 20 日动量） | 上行 1468 / 震荡 1372 / 下行 1295 |

【你的任务】
提出 **6 条**「什么样的信号更可靠 / 更不可靠」的可检验假设，覆盖不同的维度。

【输出格式】严格 JSON 数组，每项：
{
  "id": "H1",
  "hypothesis": "一句话说清假设（中文）",
  "theory": "理论依据，2-3 句（中文）",
  "when": [ {"feature": "特征名", "op": ">=", "threshold": 1.5} ],
  "predict": "high",
  "note": "阈值为什么取这个（可选，一句）"
}

when 的语法：
  · 数值特征用 {"feature": "名字", "op": ">=" | ">" | "<=" | "<", "threshold": 数值}
  · 分类特征用 {"feature": "名字", "in": ["取值1", "取值2"]}
  · when 里多个条件之间是 **AND**（全部满足才算「满足条件」组）
  · 每组信号数不要少于 200 条（总样本 4135 条）

predict 取值：
  · "high" = 满足 when 的那组，后续表现**更好**
  · "low"  = 满足 when 的那组，后续表现**更差**

只输出 JSON 数组，不要任何其他文字。
