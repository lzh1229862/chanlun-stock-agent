# 科技风界面静态稿

> **阶段说明**：这里是最初的视觉方向稿（纯 HTML + 截图，未接任何后端）。
> 该方向已落地到真实界面：`skin.py`（双皮肤令牌 + 全局样式）+ `.streamlit/config.toml`。
> 真实界面截图见本目录 `real-*.png`。

## 最终形态：双皮肤

| 文件 | 内容 |
| --- | --- |
| `real-night-top.png` | 夜晚 UI · 单股分析（头部带 / 读数卡 / K 线） |
| `real-night-table.png` | 夜晚 UI · 信号明细 + 回测表 |
| `real-day-top.png` | 白天 UI · 单股分析 |
| `real-day-table.png` | 白天 UI · 信号明细 + 回测表 |
| `real-day-pool.png` | 白天 UI · 自选股与日报 |
| `real-night-pool.png` | 夜晚 UI · 自选股与日报 |

切换开关在侧边栏左下角：**🌙 夜晚 / ☀️ 白天**，默认夜晚。

## 色板（已核算对比度）

### 夜晚（深空终端）

| 用途 | 色值 | 在 `#0A101E` 上的对比度 |
| --- | --- | --- |
| 页面底 | `#0A101E` | — |
| 卡片 | `#111A2E` | — |
| 正文 | `#E8ECF6` | 16.1:1 |
| 次要文字 | `#C3CCE0` | — |
| 弱化文字 | `#8C99B4` | 7.9:1 |
| 青（强调 / 买点） | `#22D3EE` | 10.5:1 |
| 琥珀（卖点 / 警示） | `#FFB020` | 10.4:1 |
| 红（涨） | `#FF4D6D` | 6.1:1 |
| 绿（跌） | `#00C896` | 10.0:1 |
| 紫（中枢） | `#7C5CFF` | 4.4:1 |

### 白天（同一骨架换浅色）

| 用途 | 色值 |
| --- | --- |
| 页面底 / 卡片 | `#F4F7FC` / `#FFFFFF` |
| 正文 / 次要 | `#16233D` / `#3D4D6B` |
| 青（强调） | `#0E7490` |
| 红（涨）/ 绿（跌） | `#D92D48` / `#0F9D63` |
| 紫（中枢）/ 琥珀 | `#5B4BE0` / `#C27803` |

**语义分层**：红/绿只说价格方向（守住 A 股红涨绿跌），青/琥珀只说系统判断（买/卖），紫只标中枢 —— 三套语义不串味。
