# 缠论股票分析 Agent PRD

- 版本：v1.0
- 日期：2026-09-17
- 运行环境：Windows + Python
- 目标用户：个人投资者 / 量化爱好者（懂一些编程，非专业量化开发者）

## 1. 项目背景与目标

### 1.1 背景

用户希望基于缠论，对 A 股进行自动分析，输出买卖点判断和分析结论。
传统缠论分析依赖人工画线，效率低、主观性强。
本项目用程序化方式实现缠论结构识别与买卖点信号生成，并用大模型生成可读报告。

### 1.2 目标

构建一个运行在 Windows 上的 Python Agent，实现：

- 自动获取 A 股日线 K 线数据。
- 用 czsc 计算缠论结构：分型、笔、中枢、三类买卖点。
- 对信号进行过滤和轻量回测统计。
- 用 DeepSeek 生成自然语言分析报告。
- 收盘后自动运行一次，输出 Markdown 报告。

### 1.3 非目标

以下内容明确不在 v1.0 范围内：

- 不接券商接口，不自动下单。
- 不做实时盘中监控。
- 不做分钟级多级别联立。
- 不做基本面、新闻、公告分析。
- 不做全市场扫描。
- 不做 GUI 桌面应用。

## 2. 用户与使用场景

### 2.1 目标用户

- 懂一些 Python，能改配置、看日志。
- 了解缠论基本概念，但不想手动画线。
- 希望每天收盘后拿到一份自选股的缠论分析报告。

### 2.2 核心使用场景

**场景一：每日收盘后分析**

用户在交易日收盘后运行 Agent，Agent 自动：

1. 更新自选股日线数据。
2. 计算缠论结构和买卖点。
3. 过滤不可交易信号。
4. 统计历史信号表现。
5. 生成 Markdown 报告。
6. 调用 DeepSeek 生成自然语言总结。

**场景二：研究调试**

用户在 Jupyter Notebook 中：

- 查看单只股票的缠论结构。
- 校准 czsc 信号与缠论术语的映射。
- 调整过滤规则和回测参数。

**场景三：历史复盘**

用户查询 SQLite 中的历史信号和回测统计，验证规则有效性。

## 3. 功能需求

### 3.1 数据获取

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| F1.1 | 拉取 A 股日线 | 通过 AKShare 获取指定股票日线 | P0 |
| F1.2 | 前复权处理 | 使用前复权价格，避免除权干扰 | P0 |
| F1.3 | 增量更新 | 只拉取缺失日期数据 | P0 |
| F1.4 | 本地缓存 | K 线存 Parquet，按股票分文件 | P0 |
| F1.5 | 数据校验 | 检查完整性、缺失交易日、异常价格 | P0 |
| F1.6 | 股票池管理 | 支持手工自选股，预留指数成分股扩展 | P0 |

字段要求：date, open, high, low, close, volume, amount

关键约束：

- 收盘后 18:00 之后运行，确保当日日线数据完整，同时避开 DeepSeek 高峰计价时段（高峰为北京时间周一至周五 9:00-12:00、14:00-18:00，空闲时段单价为高峰的 5 折）。
- 校验不通过的股票跳过，不生成信号。

### 3.2 缠论计算

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| F2.1 | 分型识别 | 用 czsc 计算顶底分型 | P0 |
| F2.2 | 笔识别 | 用 czsc 计算笔 | P0 |
| F2.3 | 中枢识别 | 用 czsc 计算中枢 | P0 |
| F2.4 | 买卖点识别 | 识别三类买卖点 | P0 |
| F2.5 | 术语映射 | 把 czsc 信号映射为缠论术语 | P1 |
| F2.6 | 批量计算 | 对自选股逐只计算，单只失败不影响其他 | P0 |
| F2.7 | 信号持久化 | 信号写入 SQLite，支持去重和查询 | P0 |

关键决策：

- 不直接暴露 czsc 数据结构，转成统一格式。
- 第一版先记录 czsc 原始信号，映射规则可迭代。

### 3.3 信号过滤

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| F3.1 | ST 过滤 | 排除 ST、*ST 股票 | P0 |
| F3.2 | 次新股过滤 | 排除上市不足 N 个月的股票 | P1 |
| F3.3 | 涨跌停过滤 | 排除当日涨停/跌停无法成交的标的 | P1 |
| F3.4 | 量能过滤 | 可选，排除成交量异常标的 | P2 |
| F3.5 | 信号标注 | 区分"结构信号"和"可交易信号" | P0 |

### 3.4 轻量回测

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| F4.1 | 信号后统计 | 统计信号后 5/10/20 日涨跌幅 | P0 |
| F4.2 | 最大回撤 | 统计信号后最大回撤 | P0 |
| F4.3 | 胜率统计 | 按信号类型统计胜率 | P0 |
| F4.4 | 防未来函数 | 按时间切片逐日推进 | P0 |
| F4.5 | 结果持久化 | 回测统计写入 SQLite | P0 |
| F4.6 | 信号优先级 | 按类型、胜率、结构位置排序 | P1 |

关键约束：

- 回测独立于实时分析模块。
- 信号生成只使用信号日及之前的数据。

### 3.5 报告生成

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| F5.1 | Markdown 报告 | 每只股票含结论、结构、买卖点理由、回测参考 | P0 |
| F5.2 | 按日期归档 | 报告存 reports/YYYY-MM-DD/ | P0 |
| F5.3 | 信号列表 | 当日信号汇总表 | P0 |
| F5.4 | K 线图标注 | 可选，标注分型、笔、中枢、买卖点 | P2 |

报告内容要求，每只股票包含：

- 一句话结论。
- 当前缠论结构（笔、中枢位置）。
- 买卖点类型和理由。
- 回测统计参考。
- DeepSeek 自然语言总结。

### 3.6 大模型集成

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| F6.1 | DeepSeek 调用 | 封装 API，支持重试、超时 | P0 |
| F6.2 | 缓存 | 避免重复调用 | P0 |
| F6.3 | 成本记录 | 记录 token 消耗和费用 | P1 |
| F6.4 | 提示词模板 | 与代码分离，放 config/prompts/ | P0 |
| F6.5 | 只对有信号股票调用 | 无信号股票跳过 LLM | P0 |

关键决策：

- 大模型只做解释、归纳、风险提示。
- 不参与买卖点判断。
- 提示词明确写"只解释结构，不给买卖建议"。
- 模型名使用 deepseek-flash（deepseek-chat 已下线，勿再使用）。
- 必须显式关闭思考模式：extra_body={"thinking": {"type": "disabled"}}。思考模式默认开启且 effort 默认 high，不关闭会导致输出 token 与费用成倍增加。

### 3.7 Agent 编排

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| F7.1 | LangGraph 编排 | 串联全流程 | P0 |
| F7.2 | 条件分支 | 无信号跳过 LLM；数据异常走告警 | P1 |
| F7.3 | CLI 入口 | 支持 --date、--stocks、--no-llm | P0 |
| F7.4 | 日志 | 记录每步执行状态和耗时 | P0 |

主流程：

```
拉数据 → 校验 → 缠论计算 → 信号过滤 → 回测统计 → 报告生成 → DeepSeek 总结 → 输出
```

## 4. 非功能需求

### 4.1 性能

- 10 只股票全流程运行时间 < 5 分钟（不含 LLM）。
- 含 LLM 调用 < 10 分钟。
- 增量更新只拉缺失数据。

### 4.2 可靠性

- 单只股票失败不影响整体。
- 数据校验不通过跳过该股票。
- LLM 调用失败降级为纯规则报告。

### 4.3 可维护性

- 配置与代码分离。
- 模块分层清晰，可独立替换。
- 关键决策有注释和文档。

### 4.4 可扩展性

- 股票池可扩展到沪深 300/中证 500。
- 数据源可替换。
- 缠论库可替换。
- 大模型可替换。

### 4.5 成本

- DeepSeek 只对有信号股票调用。
- 加缓存，避免重复调用。
- 记录每日 token 消耗。

### 4.6 合规

- 报告明确标注"非投资建议"。
- 不接自动下单。
- 不承诺收益。

## 5. 技术架构

### 5.1 分层设计

| 层 | 职责 | 模块 |

| 数据层 | 拉取、清洗、存储 | data_fetcher.py、data_validator.py |

| 组件 | 选型 | 理由 |
| --- | --- | --- |
| 语言 | Python 3.10/3.11 | czsc 兼容性好 |

| 编排 | LangGraph | 支持条件分支 |
| 报告 | Markdown | 可读、可归档 |
| 环境 | venv 或 conda | Windows 兼容 |

```

   ↓
```

## 9. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| czsc 在 Windows 装不上 | 阻塞开发 | 阶段 0 优先验证，必要时用 conda |
| czsc 信号与缠论术语不一致 | 信号不可信 | 先记录原始信号，人工校准 |
| 日线三类买卖点信号稀少 | 报告内容少 | 区分"新信号"和"当前区域" |
| AKShare 数据延迟 | 信号错误 | 收盘后 18:00 之后运行，加校验 |
| DeepSeek 成本超预期 | 费用高 | 只对有信号股票调用，加缓存 |
| 回测未来函数 | 结果虚高 | 按时间切片逐日推进 |
| 日线数据除权干扰 | 结构错误 | 用前复权 |

## 11. 附录：术语表

| 术语 | 说明 |
| --- | --- |
| 分型 | 缠论中顶底分型，构成笔的基础 |
| 笔 | 相邻分型之间的走势 |
| 中枢 | 至少三个连续次级别走势的重叠区间 |
| 第一类买点 | 下跌趋势末端出现的买点 |
| 第二类买点 | 第一类买点后回抽不破前低的买点 |
| 第三类买点 | 中枢突破后回踩不破中枢的买点 |
| 结构信号 | czsc 计算出的原始信号 |
| 可交易信号 | 经过过滤后，理论上可执行的信号 |
